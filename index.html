SUPERTABELLA VOLPESola lettura

Guida completa allo scambio fra Italia ed estero di atti e documenti pubblici — ricerca per Stato, forma di legalizzazione, autorità Apostille e note. I dati sono caricati dal file supertabella_volpe.csv.

⚠️ Impossibile caricare il file dei dati.
Il sito legge i dati dal file supertabella_volpe.csv, che deve trovarsi nella stessa cartella di questa pagina HTML.
Se hai aperto la pagina con doppio clic e vedi questo messaggio, il tuo browser blocca la lettura di file locali: usa Firefox, oppure avvia un piccolo server nella cartella con python -m http.server e apri http://localhost:8000, oppure pubblica entrambi i file su un hosting web.

Dati ricavati dalla "Supertabella" a cura del Dott. Alberto Volpe (Ministero dell'Interno) e dalla tabella di stato HCCH della Convenzione dell'Aja (agg. 30.06.2026). Per gli Stati senza esenzioni vale la regola generale: legalizzazione diplomatica o consolare per gli atti pubblici, legalizzazione prefettizia per gli atti consolari. Per aggiornare i contenuti modifica il file CSV e ricarica la pagina. Uso orientativo: fonte primaria restano i siti ufficiali.
