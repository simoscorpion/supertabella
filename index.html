SUPERTABELLA Web

Guida allo scambio fra Italia ed estero di atti e documenti pubblici, nonché alle procedure per il loro riconoscimento, in particolare per la richiesta della cittadinanza italiana .

⚠️ Impossibile caricare il file dei dati.
Il sito legge i dati dal file supertabella_volpe.csv, che deve trovarsi nella stessa cartella di questa pagina.
Se hai aperto la pagina con doppio clic e vedi questo messaggio, il browser blocca la lettura di file locali: usa Firefox, oppure avvia un server con python -m http.server e apri http://localhost:8000, oppure pubblica entrambi i file su un hosting (es. GitHub Pages).
Stato di provenienza degli atti e documenti Atti dello stato civile Certificati penali Atti e documenti consolari¹ Parte della Convenzione dell'Aja Note(le denominazioni di atti e documenti dipendono dalle norme negli Stati di rilascio — per le formalità richieste prima della vigenza, vedi NOTA ESPLICATIVA punto 1)

Regola generale: gli atti e documenti pubblici (a eccezione di quelli consolari¹) provenienti da ogni Stato non indicato nella tabella devono avere la legalizzazione diplomatica o consolare; gli atti e documenti consolari devono avere la legalizzazione prefettizia³, salvo esenzioni (art. 33, commi 2, 4, 5 del D.P.R. 28 dicembre 2000, n. 445).
Atti e documenti rilasciati dalle rappresentanze diplomatiche o consolari estere in Italia. Legalizzazione delle rappresentanze diplomatiche o consolari italiane. Legalizzazione di competenza della Prefettura — Ufficio territoriale del Governo.
